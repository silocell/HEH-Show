Built safe for school

These checks run on the Launchpad's own server, so they can't be switched off from a browser.

  • A safety check on every messageChat messages and AI questions are read by a safety model following a written school policy. Threats, sexual content and self-harm are blocked, and anyone who seems at risk is pointed to Childline.
  • Personal details taken outNames, emails, phone numbers, postcodes, addresses and passwords are removed before anything reaches an AI or is saved.
  • Speed limitsEach pupil can send only a few messages a minute, so nobody can flood the chat or run up AI costs.
  • Switches for every partThe Shop, Game Maker, the AI and more can be turned off for everyone or for one pupil, instantly.
  • One switch to close everythingMaintenance mode shuts every Launchpad site at once while it's being fixed.
  • School accounts onlySign-up is limited to the school's email domain, and photos need approving before anyone else sees them.

How it's built

Plain web code, a self-hosted server and a team of AIs, run almost entirely on free tiers.

Websites. Plain HTML, CSS and JavaScript on GitHub Pages: fast, free and easy to read.

Server. A self-hosted Supabase (Postgres, sign-in, storage and Deno functions) on Oracle Cloud's free tier.

AI. Free AI services with automatic fall-back, plus Claude, all through the server so keys never reach the browser.

Apps. Android, Windows, Mac, Linux and iPhone apps, built automatically by GitHub Actions.
