Keeping pupils safe

Built for school from the start. The checks run on the Launchpad's own server, not just in the browser.

  • Safety check on every messageChat messages and AI questions go through a safety model with a written school policy. Threats, sexual content and self-harm are blocked; anyone who seems at risk is pointed to Childline.
  • Personal information removedNames, emails, phone numbers, postcodes, addresses and passwords are taken out before anything reaches an AI or is saved.
  • Speed limitsEach person can only send a few messages a minute, so nobody can flood the chat or run up AI costs.
  • Admin switchesThe Shop, Game Maker, AI chat and more can be turned off for everyone or one pupil, instantly.
  • Maintenance lockOne switch closes every Launchpad site at once, while the owner keeps access to fix things.
  • School accounts onlySign-up is limited to the school's email domain, and photos need the owner's approval.

How it's built

Mostly free and open technology, run on free tiers.

  • WebsitesPlain HTML, CSS and JavaScript, hosted on GitHub Pages - one repository per site.
  • ServerA self-hosted Supabase (Postgres database, sign-in, storage and Deno edge functions) on an Oracle Cloud free-tier server in London.
  • AISeveral free AI services (Groq, Cloudflare, OpenRouter, Cohere) with automatic fall-back, plus Claude, all through the Launchpad's server so keys are never in the browser.
  • AppsLightweight Android, Windows, Mac, Linux and iPhone apps that open the Launchpad, built automatically on GitHub Actions.
